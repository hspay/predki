# Predki 0.3 — React + Vite

Семейное древо: древо, карта миграций, прогресс (созвездие достижений), люди, ИИ-архивариус (beta).
Эта версия собрана из актуального HTML-прототипа от 29.09.2026 и повторяет его один в один.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/ (открывается с любого статического хостинга и позже в Capacitor)
```

Нужен Node.js 18+. Данные хранятся в браузере (IndexedDB). Кнопка «Экспорт» в «Настройках» сохраняет JSON-файл, «Импорт» загружает его обратно.

## Что внутри

```
src/
  App.tsx                 каркас: меню, страницы, панель человека, модалка, уведомления
  lib/core.ts             данные семьи (S), сохранение, навигация, даты ДД.ММ.ГГГГ, отец по отчеству
  lib/progress.ts         43 достижения, метрики, правила открытия
  lib/treeLayout.ts       раскладка древа (поколения, пары, минимум пересечений)
  lib/extractor.ts        мок ИИ-архивариуса (текст → черновики карточек)
  lib/i18n.ts             тексты RU + EN
  lib/world.ts            контур мира и справочник городов: ~100 избранных + все 1 205 городов России
  lib/citiesRu.ts         данные городов России (из пакета russia-cities-data, ISC), с падежами
  lib/avatars.ts          аватары по умолчанию: выбор по полу и возрасту (картинки в assets/avatars)
  lib/sample.ts           демо-семья Ветровых и примеры для архивариуса
  lib/landing.js          приветственный лендинг (GSAP + плавная прокрутка Lenis), без React
  lib/vendor/lenis.mjs    Lenis 1.3.26 (MIT), положен в проект, чтобы не нужен был npm install
  landing.css             стили лендинга, все под #landing
  assets/                 скриншот прогресса для лендинга
  lib/sky.js              звёздное небо на canvas
  lib/firstRun.ts         первый вход в пустое приложение: 5 шагов, древо проступает из тумана
  lib/treeStyle.ts        стиль древа: 5 фонов, название семьи над древом, формы фамилий
  lib/fog.ts              туман на canvas (онбординг и фон древа)
  components/             Sidebar, PersonPanel, AddRelativeModal, Onboarding, FirstRun, TreeStyle, Toasts, Avatar
  pages/                  TreePage, MapPage, ProgressPage, PeoplePage, ArchivistPage, SettingsPage
```

Как устроены данные: одна семья лежит в `S`, любое изменение идёт через `commit()` — он сохраняет данные, пересчитывает достижения и перерисовывает интерфейс.
